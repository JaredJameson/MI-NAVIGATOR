## Feature #48 - Report Sharing Expiration ✅

**Implementation Status:** Complete (bug fixed and fully tested)

**Problem Identified:**
The existing share link expiration check had a timezone bug:
- Used `datetime.now(expires_at.tzinfo)` which could create timezone-naive datetime
- This caused the expiration check to fail, allowing expired links to remain accessible

**Bug Fix (backend/app/api/v1/endpoints/reports.py):**

Changed from:
```python
expires_at = datetime.fromisoformat(share_link["expires_at"].replace("Z", "+00:00"))
if datetime.now(expires_at.tzinfo) > expires_at:
    raise HTTPException(status_code=410, detail="Share link has expired")
```

To:
```python
from datetime import datetime, timezone
expires_at = datetime.fromisoformat(share_link["expires_at"].replace("Z", "+00:00"))
current_time = datetime.now(timezone.utc)
if current_time > expires_at:
    raise HTTPException(status_code=410, detail="Share link has expired")
```

**Test Endpoint Added (lines 4221-4246):**
```python
@router.post("/test/share/expire-link/{share_token}")
async def test_expire_share_link(
    share_token: str,
    seconds_until_expiry: int = Query(default=5)
):

    SHARE_LINKS[share_token]["expires_at"] = new_expires_at.isoformat() + "Z"
    return {...}
```
