### 💡 Flexbox + Truncate Pattern

**CSS Rule:** For `truncate` to work in flexbox child:
```css
.parent {
  display: flex;
  flex: 1;
  min-width: 0;  /* ← REQUIRED! */
}
.child {
  overflow: hidden;
  text-overflow: ellipsis;
  white-space: nowrap;
}
```

**Why:** Flexbox children default to `min-width: auto`, preventing shrinking below content size.
