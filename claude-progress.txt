## Feature #39 - Report Editor Section Reordering ✅

**Implementation Status:** Fully implemented with frontend + backend changes

**Frontend Changes (frontend/src/app/reports/[id]/page.tsx):**
1. Added @dnd-kit imports (DndContext, SortableContext, useSortable, etc.)
2. Created `SortableSectionWrapper` component:
   - Visual drag handle icon (6-dot grip)
   - Hover effects (gray-400 → gray-600)
   - Opacity feedback during drag (0.5)
   - Tooltip: "Przeciągnij aby zmienić kolejność"
3. Added state management:
   - `sortedSections` state to track section order independently
   - `useEffect` to sync with report.sections on load
4. Implemented drag & drop logic:
   - Created sensors (PointerSensor, KeyboardSensor)
   - `handleDragEnd` function using arrayMove()
   - Wrapped edit mode sections in DndContext/SortableContext
5. Updated save logic:
   - Changed from `report.sections` to `sortedSections`
   - Preserves new order when saving to backend

**Backend Changes (backend/app/api/v1/endpoints/reports.py):**
1. Fixed PUT /reports/{report_id} endpoint (lines 1361-1391):
   - Previously: Updated section content in-place (order not preserved)
   - Now: Replaces entire sections array to maintain order
2. Added order change detection for audit log:
   - Compares old_section_ids vs new_section_ids
   - Logs "Section order changed" when order differs
3. Created `updated_sections` list:
   - Iterates through sections in new order
   - Detects content/title changes
   - Builds fresh array preserving frontend order

**Testing Results:**

✅ Step 2: Identify section order - Original: 1,2,3,4,5,6

**Note on Testing:**
