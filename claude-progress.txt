## Bug Fix: datetime Import Error

**Problem Identified:**
```
UnboundLocalError: cannot access local variable 'datetime' where it is not associated with a value
```

**Root Cause:**
- Function `generate_mock_response` had local import on line 121: `from datetime import datetime`
- Another local import on line 2328: `from datetime import datetime, timedelta`
- Python treats `datetime` as local variable in entire function scope
- Usage of `datetime.utcnow()` on line 194 (before second import) caused UnboundLocalError

**Solution:**
- Consolidated imports to single location (line 121)
- Changed to: `from datetime import datetime, timedelta`
- Removed duplicate import on line 2328

**Verification:**
- Tested company lookup: "Lookup company with NIP: 5260016831"
- Received successful response with timestamp: "Dane pobrano: 18.01.2026, 17:37:52"
- WebSocket connection working
- Zero errors in console
