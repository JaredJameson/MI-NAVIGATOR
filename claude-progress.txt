## Bug Fixes This Session

### Chat Authentication Fixed
**Problem:** Chat conversations endpoints returned 401 Unauthorized in dev mode

**Solution:**
- Changed `Depends(get_current_user)` → `Depends(get_current_user_optional)`
- Added fallback: `user_id = str(current_user.id) if current_user else "dev_user_123"`
- Applied to: list_conversations, create_conversation, get_conversation, send_message

**Result:** Chat now works without login in development mode
