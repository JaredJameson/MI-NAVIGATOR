## TECHNICAL INSIGHTS

### Service Worker Configuration

**Current Setup (next-pwa):**
```javascript
// Development: NetworkOnly strategy (no caching)
registerRoute(/.*/i, new NetworkOnly({ cacheName: "dev" }), 'GET')

// Production: NetworkFirst strategy
registerRoute(/^https?.*/, new NetworkFirst({
  cacheName: "offlineCache",
  plugins: [new ExpirationPlugin({
    maxEntries: 200,
    maxAgeSeconds: 86400
  })]
}), 'GET')
```

**Issue:** Runtime caching doesn't work with Next.js App Router because:
- Client-side navigation uses `useRouter()` (no HTTP requests)
- RSC responses are JSON payloads (not HTML)
- Service Worker doesn't intercept client-side route changes

### User Roles

**Defined in app_spec.txt:**
- **guest:** Can view landing, no access to features
- **user:** Full access to chat/analysis/reports, no admin
- **admin:** All user permissions + user management + system stats
