## Technical Notes

### URL Synchronization Pattern

**Reading from URL:**
```typescript
const searchParams = useSearchParams()
const [filterType, setFilterType] = useState(searchParams.get('type') || '')
```

**Writing to URL:**
```typescript
useEffect(() => {
  const params = new URLSearchParams()
  if (filterType) params.set('type', filterType)
  if (filterTag) params.set('tag_id', filterTag)

  const newUrl = params.toString() ? `/reports?${params.toString()}` : '/reports'
  router.push(newUrl, { scroll: false })
}, [filterType, filterTag, router])
```

**Benefits:**
- Shareable filtered views
- Bookmarkable searches
- Browser back/forward works
- Direct deep linking support

### Profile Management

**Data Flow:**
1. User edits form fields
2. Form state updates (React state)
3. User clicks "Save Changes"
4. API call to `/api/users/profile` (PATCH)

**Fields Updated:**

### Billing/Subscription Flow

**Architecture:**
1. User views current plan on /settings/billing
2. Clicks "Upgrade Plan" → /settings/billing/upgrade
3. Selects desired plan (Starter/Professional/Enterprise)
4. Payment form appears

6. Clicks "Pay $X"

9. Database updated with new plan
