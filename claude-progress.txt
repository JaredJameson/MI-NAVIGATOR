### Challenge

### What Was Built (9 new files, 3 modified):

**Backend Implementation:**
1. ✅ **Webhook Model** (`backend/app/models/webhook.py`)
   - Database schema with retry fields
   - Enums: WebhookEvent, WebhookStatus
   - Fields: retry_count, max_retries, next_retry_at, last_error

   - Exponential backoff: 2^n minutes (2, 4, 8, 16, 32 min)
   - Async delivery with httpx
   - Auto-retry scheduling with asyncio
   - Status tracking: pending → retrying → delivered/failed

3. ✅ **API Endpoints** (`backend/app/api/v1/endpoints/webhooks.py`)
   - POST /webhooks - Create
   - GET /webhooks - List
   - GET /webhooks/{id} - Details

   - DELETE /webhooks/{id} - Delete
   - POST /webhooks/{id}/test - Manual trigger

4. ✅ **Database Migration** (`backend/alembic/versions/a1988e479015_add_webhooks_table.py`)
   - Webhooks table with indexes
   - Enum types for event_type and status

**Test Infrastructure:**
5. ✅ **Test Webhook Server** (`test_webhook_server.py`)
   - Runs on port 8001
   - Modes: success (200) / fail (500)
   - Logs all webhook attempts
   - REST API for mode control

### Event Types Supported:
- report.created
- report.updated
- report.deleted
- analysis.completed
- alert.triggered

### Retry Mechanism:
```
Retry 1: 2 minutes  (2^1)
Retry 2: 4 minutes  (2^2)
Retry 3: 8 minutes  (2^3)
Retry 4: 16 minutes (2^4)
Retry 5: 32 minutes (2^5)
Max: 5 retries (configurable)
```
