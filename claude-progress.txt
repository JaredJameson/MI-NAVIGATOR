## TECHNICAL HIGHLIGHTS

### A/B Testing Architecture

**Consistent Hashing Algorithm:**
```python
def get_or_assign_variant(user_id, session_id, experiment_name):
    identifier = user_id if user_id else session_id
    hash_input = f"{experiment_name}:{identifier}"
    hash_value = int(hashlib.md5(hash_input.encode()).hexdigest(), 16)
    variant = "B" if hash_value % 2 == 0 else "A"
    return variant
```

**Benefits:**
- Deterministic: Same input → same output
- Stateless: No database required for variant assignment
- Fast: O(1) computation
- Fair: ~50/50 split between A and B

**Session Management:**
- 30-day cookie: `ab_session_id`
- HTTP-only + SameSite=Lax (security)
- Survives page refreshes and browser sessions

**React Hook Usage:**
```typescript
const { variant, track } = useABTest('my_experiment')

// Show different content based on variant
{variant === 'A' ? <VersionA /> : <VersionB />}

// Track events
await track('button_click')
```
