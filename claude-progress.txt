**Dynamic Plan Generation Logic:**
- Base step: Data Collection (always included)
- Market Analysis: Added for scope = market_context, competitive, industry_deep_dive
- Competitive Analysis: Added for scope = competitive, industry_deep_dive
- Industry Ecosystem: Added for scope = industry_deep_dive
- Synthesis step varies by depth:
  - executive_summary → "Executive Summary" (2-3 min)
  - standard/detailed → "Analysis & Synthesis" (5-8 min)
  - exhaustive → "Comprehensive Report" (15-20 min)

**WebSocket Message Flow:**
1. User sends: "Analyze FADO..."
2. Backend detects research keywords → sends brief_question (objective)
3. User answers objective → Backend sends brief_question (scope)
4. User selects scope → Backend sends brief_question (depth)
5. User selects depth → Backend generates plan → sends plan message
6. User confirms plan → Backend starts research with progress updates
