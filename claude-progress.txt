## Technical Notes

### Browser Back Button Behavior

**Next.js App Router Navigation:**
- Uses client-side routing (no full page reload)
- Browser back triggers `popstate` event
- URL updates synchronously
- Component re-render happens asynchronously
- Typical render delay: 2-3 seconds

**Testing Approach:**
- Always wait 2-3 seconds after browser back
- Verify both URL and page content
- Check for proper component mounting
- Screenshots should be taken after wait period

### Multi-Tab Session Management

**Session Cookie Behavior:**
- Cookies are shared across all tabs in same browser
- `httpOnly` cookies (if used) also shared
- localStorage/sessionStorage may differ:
  - localStorage: Shared between tabs
  - sessionStorage: Separate per tab

**Application Implementation:**
- Uses shared authentication cookies ✅
- Session persists across page refreshes ✅
- No tab-specific session isolation
- All tabs see same user data
