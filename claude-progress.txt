### Clipboard API Best Practices

**Modern Implementation:**
```typescript
const handleCopy = async () => {
  try {
    await navigator.clipboard.writeText(content)
    setFeedback(true)
    setTimeout(() => setFeedback(false), 2000)
  } catch (err) {
    console.error('Copy failed:', err)
  }
}
```

**Key Points:**
- ✅ Use navigator.clipboard.writeText() (not execCommand)
- ✅ Always async/await
- ✅ Always try-catch for error handling
- ✅ Provide visual feedback (checkmark, "Copied!" text)
- ✅ Auto-reset feedback after 2-3 seconds
- ✅ Requires HTTPS or localhost (security)
- ✅ Requires user gesture (click/tap)
- ✅ Works across all modern browsers

- ✅ Use clear, non-technical language when possible

### ✅ Feature #133: File upload size validation - PASSED

Fixed critical bug where error messages were cleared immediately after being set, preventing users from seeing validation errors.

**Bug Discovered:**
- `setError()` was called when file > 50MB (line 676)
- `setError('')` was ALWAYS called after forEach (line 689)
- Result: Error message appeared for 1ms then disappeared

**Bug Fix:**
```typescript
// BEFORE (buggy)
Array.from(files).forEach(file => {
  if (file.size > maxSize) {
    setError(`File ${file.name} is too large. Max size is 50MB.`)
    return  // Only exits forEach, not function
  }
})
setError('')  // ALWAYS clears error!

// AFTER (fixed)
let hasError = false
Array.from(files).forEach(file => {
  if (file.size > maxSize) {
    setError(`File ${file.name} is too large. Max size is 50MB.`)
    hasError = true
    return
  }
})
if (!hasError) {  // Only clear if no errors
  setUploadedFiles(prev => [...prev, ...validFiles])
  setError('')
}
```
