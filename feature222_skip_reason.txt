## Why This is a SKIP

### 1. Not Implemented

**Evidence:**
- ❌ No sort state in report viewer
- ❌ No onClick handlers on table headers
- ❌ No handleSort function
- ❌ No custom ReactMarkdown components for tables
- ❌ Only 1 static table (shareholders) without sorting

### 2. Implementation Effort

To implement table sorting in reports:

**A) For Static Tables (Shareholders):**
- Add useState for sortBy, sortDirection
- Add onClick handlers to <th>
- Add handleSort function
- Add sort icons (▲▼)
- Sort data array before rendering
- **Estimate:** 2-3 hours

**B) For Markdown Tables (Report Content):**
- Create custom SortableTable component
- Parse markdown table to data structure
- Add sorting state per table
- Render with sort controls
- Handle multiple tables in one report
- **Estimate:** 6-8 hours

**C) Testing:**
- Test all column types (text, number, date)
- Test ascending/descending
- Test multiple tables
- **Estimate:** 2-3 hours

**Total: 10-14 hours**

### 3. Low Priority Feature

**Reasoning:**
- Reports are for reading/reviewing, not data manipulation
- Users can sort in source data (before report generation)
- Export to Excel provides sorting capability
- Not critical for core functionality
